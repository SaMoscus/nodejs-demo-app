#Project: Automated CI/CD Pipeline for a Node.js Application

Objective: Automate testing, Docker image building, and image publishing using GitHub Actions and Docker Hub.

Technologies:
- Node.js
- Git and GitHub
- GitHub Actions
- Docker
- Docker Hub
- YAML
Implementation:
- Created a sample Node.js web application.
- Implemented automated application tests.
- Created a Dockerfile to containerize the application.
- Configured a GitHub Actions workflow triggered by pushes to main.
- Configured GitHub secrets for Docker Hub authentication.
- Automated Docker image tagging and publishing.
- Verified the published image by running it locally.
Outcome: Established an automated pipeline that tests the application before publishing its Docker image.
